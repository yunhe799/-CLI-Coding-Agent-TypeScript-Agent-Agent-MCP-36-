# 2 分钟演示脚本（照着点就行）

> 目的是**一条故事线**：让不懂 coding agent 的人也在 2 分钟内看懂"这东西解决了什么问题"。别演示功能清单。

## 录制前

```powershell
cd E:\coding项目\my-coding-agent
npm install          # 第一次才需要
npm run web          # 演示台（会自动先编译），然后浏览器开 http://localhost:8787
```

> 确认 `.env` 里有 key。**推荐用网页示意，不用终端**：页面里工具调用链、MCP 连接状态、逐字回答都看得清清楚楚，字号也大，录出来比黑底终端好看得多。页面里跑的就是命令行那套代码（服务端每次请求 spawn 一次真实的 `node dist/cli.js`），不是"演示版"。

## 分镜（网页版）

| 时间 | 做什么 | 台词 |
| --- | --- | --- |
| 0:00 | 停在页面顶部，镜头扫过那排数字 | "普通聊天机器人只会回话，**Agent 会自己动手**——这是我用 TypeScript 从零手写的 CLI Coding Agent。" |
| 0:15 | 点 **🔎 考古：这段代码为什么长这样** | "它查的不是代码，是代码的**历史**。这 8 个考古工具是我自己写的 MCP server，Agent 一行代码没改就会用了。" |
| 0:45 | 点 **🛡 危险命令会被拦吗** | "闸门在**代码层**，不靠模型自觉。" |

| 1:45 | 滚回顶部数字 | "**危险命令拦截率 100%，真模型任务通过率 96.6%，每次任务 0.26 分钱。**" |

## 备选：纯终端版

## 分镜

**0:00–0:20 ｜ 一句话定位**

打开 `README.md`，念第一行：
> "普通聊天机器人只会回话，**Agent 会自己动手**。这是我用 TypeScript 从零手写的一个命令行 Coding Agent。"

**0:20–1:00 ｜ 让 Agent 考古它自己（这场戏的核心）**

```powershell
node dist/cli.js "为什么 src/context.ts 里的压缩阈值是 20？用考古工具查出来龙去脉"
```

看点：它会**自己发现并调用** `mcp__archaeology__find_introduction` / `commit_info`，最后答出"原来的 6 是演示值，读 9 个文件就触发压缩，模型于是编数字（把 104 行说成 496 行）"。

一句旁白：**"它查的不是代码，是代码的**历史**——这 8 个工具是我自己写的 MCP server，Agent 一行代码没改就学会了考古。"**

**1:00–1:30 ｜ 危险操作被拦（安全）**

```powershell
node dist/cli.js "用 run_shell 执行：git push origin main"
```

看点：命令**没有执行**，模型收到 `Denied: run_shell was blocked`。

一句旁白：**"闸门是代码层的，不靠模型自觉——这是软约束 + 硬约束的纵深防御。"**

**1:30–2:00 ｜ 拿数字收尾**

```powershell
npm test           # 5 套离线单元测试，64 项断言
npm run eval:mock  # 36 条评测用例，100%
```

然后翻到 README 的评测结果表，念：
> "**危险命令拦截率 100%，真模型任务通过率 96.6%，平均每次任务 0.26 分钱，P95 9 秒。**"

## 别说的话

- 别逐个介绍 12 个模块（没人记得住）。**只讲那条故事线**。
- 别念代码。要念就念注释里的那句"为什么"。
- 别回避失败——如果时间允许，加一句"评测里唯一那条真失败是多步任务没写完文件，我知道它差在哪"，这比全是绿灯更可信。
